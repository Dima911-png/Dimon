# ClipGenius AI — запуск с настоящей ИИ-генерацией

Это минимальный рабочий проект: сайт + Node.js сервер + подключение к Gemini API. API-ключ хранится только на сервере, не в браузере.

## Требования
- Node.js 20+ (для встроенного `fetch` и `AbortSignal.timeout`)
- API-ключ Gemini из Google AI Studio: https://aistudio.google.com/app/apikey
- Условия, доступность и бесплатные квоты API зависят от аккаунта и могут меняться. Проверь их перед запуском.

## Локальный запуск
1. Скачай и распакуй архив.
2. Создай API-ключ в Google AI Studio.
3. Открой терминал в папке проекта.
4. Задай ключ в окружении, не вставляя его в `index.html`:
   - macOS/Linux: `export GEMINI_API_KEY="твой_ключ"`
   - Windows PowerShell: `$env:GEMINI_API_KEY="твой_ключ"`
5. Запусти: `node server.js`
6. Открой `http://localhost:3000`.
7. Проверь статус: `http://localhost:3000/api/health`.

Модель по умолчанию задаётся в `server.js` как `gemini-3.6-flash`. Если она недоступна в твоём аккаунте/регионе, задай поддерживаемую модель:
- macOS/Linux: `export GEMINI_MODEL="имя-модели"`
- Windows PowerShell: `$env:GEMINI_MODEL="имя-модели"`

## Публикация в интернете
Размести папку на Node.js-хостинге, который поддерживает серверный процесс и переменные окружения. В настройках проекта добавь:
- `GEMINI_API_KEY` = секретный API-ключ
- `GEMINI_MODEL` = доступное имя модели (необязательно)
- `NODE_ENV` = `production` (если требуется платформой)

Команда запуска: `node server.js`

Не публикуй API-ключ в репозитории, в браузерном JavaScript или в публичном файле. После публикации проверь `/api/health` и попробуй создать тестовый сценарий.

## Что уже работает
- Адаптивная страница продукта.
- Реальный серверный endpoint `/api/generate`.
- Валидация полей, ограничение размера запроса и простой rate limit.
- Обработка ошибок провайдера без показа секрета пользователю.
- Проверка состояния `/api/health`.

## Что ещё не реализовано для коммерческого запуска
- Регистрация/вход и база данных пользователей.
- Подписки и платёжный провайдер.
- Персональные лимиты на аккаунт, защита от злоупотреблений на уровне пользователя и аналитика.
- Юридические страницы, политика конфиденциальности, условия использования и налоговая настройка.
- Автоматические тесты и мониторинг.

Не принимай платежи, пока не реализованы учёт подписок, лимиты и поддержка пользователей. Бесплатный доступ к API не гарантирован и может иметь ограничения.
